## ⚙️ 프로그래밍 요구 사항

- **JDK 21** 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 `Application`의 `main()`이다.
- `build.gradle` 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 `System.exit()`를 호출하지 않는다.
- **들여쓰기(indent) depth는 2까지만 허용한다.** (메서드 분리로 해결)
- **3항 연산자를 쓰지 않는다.**
- **`else` 예약어와 `switch/case` 문을 사용하지 않는다.**
- **함수(메서드)는 15라인을 넘지 않도록, 한 가지 일만 하도록 최대한 작게 만든다.**
- **Java Enum**을 적용하여 프로그램을 구현한다.
- **JUnit 5와 AssertJ**로 기능 목록이 정상 작동하는지 테스트 코드로 확인한다. (UI 로직 제외)

## ⌨️ 입출력 요구 사항

### 입력

- 로또 구입 금액: `8000`
- 당첨 번호: `1,2,3,4,5,6`
- 보너스 번호: `7`

### 출력

- 실행 결과 예시

```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개

5개 일치 (1,500,000원) - 0개

총 수익률은 62.5%입니다.
```
